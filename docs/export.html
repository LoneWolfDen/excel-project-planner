Planner and MS Project

Converts the planner workbook to a Microsoft Project file, or a Microsoft Project file to a new planner workbook: tasks, links, calendar, holidays, constraints, baseline, resources and assignments.

With a planner workbook (.xlsx)

    Download

    How

    Workbook to MS ProjectSave the workbook in Excel first (so it holds up-to-date values), choose it here, download the .xml. In MS Project: File > Open, choose the .xml, "Open as a new project".
    Upgrade a workbookMade your plan with an older version of the template? Choose that workbook with "Move it to the latest template" and download the new one: tasks, people, leave, logs, history and settings are carried over; the formulas, sheets and reports are the latest.
    MS Project to workbookIn MS Project: File > Save As > XML. Choose that file here and download the workbook. Excel calculates it when you open it. Anything the planner can't hold (a fifth predecessor, a lag in % ...) is listed here and noted on the task.

    The conversion runs on this device: no file is uploaded anywhere. The first conversion downloads the converter (Pyodide, about 10 MB), which the browser then keeps.
