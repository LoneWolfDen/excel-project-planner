Planner to MS Project

Turns the planner workbook into a Microsoft Project XML file, with tasks, links, calendar, holidays, constraints, baseline, resources and assignments.

Download the .xml

Open it in MS Project

  1. Save the workbook in Excel first, so it holds up-to-date values.
  2. In MS Project: File > Open, choose the .xml, then "Open as a new project".

The conversion runs on this device: the workbook is not uploaded anywhere. The first conversion downloads the converter (Pyodide, about 10 MB), which the browser then keeps.
